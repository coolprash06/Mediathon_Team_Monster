# Photo placement log

This file is the source-of-truth for the portfolio photo manifest. Each source
image has one website copy at `assets/photos/rush-##.jpg`, and is shown once in
both a rush-phase monitor and its location drawer.

## Classification rules

- **Morning Rush**: early activity and the quieter start of the day.
- **Afternoon Rush**: regular midday movement and lunchtime activity.
- **Peak Rush**: the strongest queues, crowding, and converging foot traffic.
- The original `.HEIC` files are converted to browser-compatible JPEG copies
  for the site. Keep the originals in the team Google Drive folder so their
  metadata remains available for the organizers.
